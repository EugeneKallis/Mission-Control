For non-trivial tasks in this project, act as a coordinator and proactively use subagents wherever they provide a clear advantage. Delegate implementation to worker subagents, and use other subagents as appropriate for planning, research, code review, testing, validation, or specialized analysis. Do not spin up subagents for small, routine operations such as committing or pushing already-reviewed changes. Have the subagent best suited to each task do the work; use isolated worktrees when parallel changes could conflict. Focus your own work on task decomposition, delegation, integration, and communicating the result, to conserve tokens.
